| (gabriel) | Operações/Infraestrutura | `Dockerfile`, `docker-compose.yml`, `cd.yml`, segredos, rollback |

## Como organizamos as atividades

- Tarefas anotadas no Quadro da Turma (a própria aplicação) ou em um GitHub Project.
- Toda mudança entra por Pull Request revisado por outra pessoa do grupo.
- Reunião curta a cada semana para conferir o que falta para a próxima entrega.
